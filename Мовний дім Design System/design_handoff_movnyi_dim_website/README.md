## Ключові токени
- **Шрифти:** Playfair Display 600 (заголовки, перше слово italic в акценті) · Instrument Sans 300/400 (текст; кирилиця — Manrope) · Poppins 100 (рейтинг 5.0)
- **Кольори:** Cream `#F9F4F0` · Ink `#262626` · Accent `#C2A58A` (Light `#D3B79D`, Deep `#A3805F`) · Beige `#F3EDE8` · Taupe `#CDBBAA` · Cocoa `#48392D` · Espresso `#18120C`. Логотип: Emerald `#1F4B3A` + Copper `#B07A4F`, підпис `#6B5B4D`
- **Форма:** радіус карток 24 · пігулки 99 · хедер 40 · тінь `0 5px 10px rgba(0,0,0,.1)`
- **Простір:** gutter 64 / 32 / 16 · секції 80–160 px · 8-pt шкала

## Секції
Хедер-плашка → Hero + скляна панель статистики → «Чому Мовний дім?» (sticky-стек) → «Мова не має для нас таємниць» (великий текст + плаваючі слова + будиночок) → «Як ми працюємо?» (4 кроки драбинкою) → стрічка установ → Bento → Відгуки + Google 5.0 → «Мені потрібен переклад для…» → Форма «Поговорімо» → Еспресо-футер → FAB.
