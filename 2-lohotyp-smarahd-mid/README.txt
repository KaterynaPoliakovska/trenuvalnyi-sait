МОВНИЙ ДІМ — пакет логотипу (кольори: смарагд + мідь, жовтень 2026)
===========================

ПАПКИ
svg/  — векторні файли (текст переведено в криві, шрифти не потрібні). Для сайту, друку, дизайнерів.
png/  — растрові з прозорим фоном: 1200 px і @2x (2400 px) по ширині; знак — 1024×1024.
pdf/  — векторні PDF для друкарні (основні версії).
web/  — favicon.ico, favicon.svg, favicon-16/32/512.png, apple-touch-icon.png (180), social-avatar-1080.png.

ВЕРСІЇ
horizontal — основна (знак ліворуч, назва праворуч)
vertical   — для квадратних форматів, вивісок, обкладинок
mark       — лише знак-будиночок (іконки, аватари, печатки)
ua / en    — українською («мовний дім · бюро перекладів») / латиницею (MOVNYI DIM · TRANSLATION BUREAU)

КОЛЬОРОВІ ВАРІАНТИ
color   — на білому / світлому фоні
reverse — на темному фоні (еспресо, смарагд, фото)
black   — одноколірний чорний (факс, гравіювання, ч/б друк)
white   — одноколірний білий (на фото, темних поверхнях)

КОЛЬОРИ
Смарагд (основний)       HEX #1F4B3A   RGB 31 75 58     CMYK ≈ 59 0 23 71
Мідь (акцент)            HEX #B07A4F   RGB 176 122 79   CMYK ≈ 0 31 55 31
Теплий сірий (підпис)    HEX #6B5B4D   RGB 107 91 77
CMYK — орієнтовна конвертація; перед тиражем попросіть у друкарні пробний відбиток.

ШРИФТИ
Назва:  Unbounded Bold (Google Fonts, безкоштовний, з кирилицею)
Підпис і тексти: Manrope SemiBold / Regular (Google Fonts)

ПРАВИЛА
• Вільне поле навколо логотипу — не менше висоти лапок «» у знаку.
• Мінімальний розмір: горизонтальний логотип — 120 px / 30 мм завширшки; знак — 16 px.
• Не розтягувати, не повертати, не міняти кольори половинок місцями, не додавати тіні й обведення.
